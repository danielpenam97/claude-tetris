# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Vanilla JS Tetris on HTML5 Canvas. No dependencies, no `package.json`, no build step, no linter, no test suite. UI strings and the README are in Spanish; keep new user-facing text in Spanish.

## Running

Open `index.html` directly, or serve the folder statically (recommended):

```bash
python -m http.server 8000   # then open http://localhost:8000
```

There are no automated tests — verify changes by playing the game in a browser.

## Architecture

Three files: `index.html` (DOM: board + hold/next/queue canvases, two side panels, three overlays), `style.css` (dark/light retro theme via CSS vars), and `game.js` (all logic, plain script with `'use strict'`, no modules). All game state lives in module-level `let` globals (`board`, `current`, `queue`, `score`, `lines`, `level`, `paused`, `gameOver`, `combo`, `energy`, `hold`, ...) that `init(modeId)` resets; the restart button calls `init()` (same mode). On load the game inits `classic` and immediately opens the mode menu (`openModeMenu` sets `gameOver = true` to halt input/loop).

Key conventions in `game.js`:

- **Piece type = color index = cell value.** `PIECES[i]` matrices are filled with the value `i`, and `COLORS[i]` is its color. Board cells store `0` (empty) or that index, so `merge()` copies shape values straight into the board. Index 0 is `null` in both arrays. Index 8 is `WILD` (board-only, `null` in `PIECES`); special pieces live at 9–13 (`PLUS`, `U_PIECE`, `Y_PIECE`, `SINGLE`, `HOLLOW`). `randomPiece()` rolls `HOLLOW_CHANCE` / `PENTOMINO_CHANCE` before falling back to the 7 classics (`* 7`), then calls `makePiece(type)`. `SINGLE` is never random: `clearLines()` sets `singleReward` on a 4+ line clear and `spawn()` makes the next piece a 1×1. `GARBAGE = 14` and `FIXED = 15` are board-only like `WILD`. Every shape must fit in 4×4 for `drawCentered()`.
- **Piece queue:** there is no `next`; `queue` holds `QUEUE_SIZE` upcoming pieces (`queue[0]` is NEXT), refilled by `fillQueue()`. Pieces get mutated while they are `current`, so anything stored for later (hold, undo snapshot) goes through `clonePiece()` / `resetPiece()` (clone + back to spawn position, keeping rotation).
- **Collision is the single source of truth.** `collide(shape, x, y)` is used for movement, rotation wall kicks (`tryRotate` tries x offsets `0, -1, 1, -2, 2`; not SRS), ghost projection (`ghostY`), gravity, and game-over detection in `spawn()`. Cells with `y < 0` are allowed above the board.
- **Piece lifecycle:** gravity/soft drop/hard drop → `lockPiece()` → `takeSnapshot()` (for undo) → `detectTSpin()` (must run before merge) → `merge()` (returns false on lock-out above the board → game over) → `applyPowerUp()` → `clearLines()` (returns count; recomputes level and `dropInterval = max(100, 1000 - (level-1)*90)`) → `scoreClear(cleared, tspin)` → `checkObjective()` → `spawn()` (shifts `queue` into `current`, game over if it collides immediately).
- **Scoring (`scoreClear`):** base = `LINE_SCORES` or `TSPIN_SCORES` × level, × `B2B_FACTOR` if this and the previous line-clearing lock were both "difficult" (Tetris or T-spin), × `combo` (consecutive line-clearing locks; any lock without lines resets it). `PERFECT_CLEAR_BONUS` × level if the board ends empty. It also fills `energy` and triggers popups/flash/shake/sound. T-spin = T piece, last successful action was a rotation (`lastMoveRotate`, cleared by any move/fall), and ≥3 diagonal corners of its center occupied.
- **Loop:** `requestAnimationFrame(loop)` accumulates `dt` into `dropAccum` and steps gravity once per `dropInterval` (× `SLOW_FACTOR` while `slowTime > 0`); also advances `elapsed`, effects, garbage timer and checks objectives. The loop stops requesting frames once `gameOver` is set. Pause, the ability menu and game over all work by `cancelAnimationFrame(animId)`; resume restarts the loop with a fresh `lastTime`.
- **Modes (`MODES`):** each mode is a bag of optional fields (`lines`, `timeLimit`, `survive`, `garbageEvery`, `fixedRows`, `invisible`, `reverseFromLevel`) read by `init`, `loop`, `draw`, `tryRotate`, `checkObjective` and `objectiveText`. Adding a mode = adding an entry; the menu is generated by `buildMenus()`.
- **Abilities (`ABILITIES`):** `applyAbility(id)` returns false when it can't apply, in which case energy is not spent and the menu stays open. Undo restores the single `undoSnapshot` from the last lock.
- **Sound** is synthesized with WebAudio in `SOUNDS` (no assets); `ensureAudio()` creates/resumes the context on the first key or click.
- **Power-ups:** `randomPiece()` gives ~`POWER_CHANCE` of pieces a `power` (from `POWERS`) plus a `mask` matrix marking the carrying cell; `mask` is rotated alongside `shape` in `tryRotate`. `lockPiece()` runs `applyPowerUp()` between `merge()` and `clearLines()`. Bomb and ray call `settleFloating()` (sticky gravity: blocks not 4-connected to the floor drop as groups); the gravity power-up instead compacts each column naively. `WILD = 8` is a board-only color index (no entry in `PIECES`); `rowComplete()` treats a row as full when its wildcards ≥ its empty cells. Freeze uses `freezeTime`, decremented in `loop` instead of accumulating `dropAccum`.
- **HUD** (`updateHUD`) is DOM text, updated after locks, soft drops, and every keydown; timer-driven text (objective, ability status) is refreshed every frame by `updateStatus()`. `#overlay` is shared by PAUSA, GAME OVER and win states; `#mode-menu` and `#ability-menu` are separate overlays.
- **Records:** `localStorage` key `records` = `{ top: [{name, score, lines, combo, mode, date}] (max `RECORDS_MAX`, sorted desc), bestCombo, maxLines }`; `loadRecords()` validates the parsed shape and returns empty data on anything corrupt. `endGame()` (losses and wins) calls `recordGameEnd()`, which always updates `bestCombo` / `maxLines` (`maxCombo` is a per-game global reset in `init`) and, if the score qualifies, stores `pendingRecord` and shows `#record-form`; `savePendingRecord()` inserts it and re-renders with the row highlighted; `init()` and `openModeMenu()` also call it, so leaving without pressing Guardar still saves (last name or "Anónimo"). `renderRecords(container, highlight)` builds the table with `textContent` only (names are user input) and is used for `#overlay-records` and `#menu-records` (refreshed in `openModeMenu`). The global keydown handler ignores events targeting inputs/textareas so typing a name doesn't trigger shortcuts.

## Coupled values

- `<canvas id="board">` size in `index.html` must equal `COLS × BLOCK` by `ROWS × BLOCK` (300×600 by default).
- `#next-canvas` and `#hold-canvas` are 120×120, which matches the hardcoded `NB = 30` × 4 cells in `drawNext()` / `drawHold()`.
- `#queue-canvas` is 120×200: 4 pieces at `QB = 12` px, 50 px apart, in `drawNext()`.
